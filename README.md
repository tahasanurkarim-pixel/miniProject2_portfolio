# Personal Portfolio Website - Mini Project 2

**Course:** Software Development I (CSE-2340)
**Assessment:** Mini Project 2 (MP2) - Responsive Website Development
**Name:** Tahasanur Karim

## About

This is my personal portfolio website made with **HTML** and **Tailwind CSS**.
In Mini Project 1 I made a portfolio using HTML and normal CSS. For this project I rebuilt
it with Tailwind CSS, gave it a new light blue theme and changed the layout of the sections.

**Live Website:** https://tahasanurkarim-pixel.github.io/miniProject2_portfolio/mp2.html

## Sections

- **Navbar** - links to every section, with a Menu button on mobile screens
- **Home** - a short introduction about me with my photo
- **Skills** - the things I work on and enjoy
- **Projects** - my C++ projects with links to their GitHub repositories
- **Contact** - my email, GitHub, LinkedIn and a contact form
- **Footer** - copyright and a Back to Top link

## Features

- Styled fully with Tailwind CSS utility classes (colors, spacing, typography, borders, shadows)
- Responsive layout for mobile, tablet and desktop using `sm:`, `md:` and `lg:` breakpoints
- Interactive elements:
  - Hover effects on navbar links, buttons, skill rows and project cards
  - Menu button that shows and hides the navigation on mobile
  - Smooth scrolling when clicking navigation links
  - Focus effect on the form inputs

## Technologies Used

- HTML5
- Tailwind CSS (CDN)
- A little JavaScript for the mobile menu
